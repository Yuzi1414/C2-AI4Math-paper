# C2 文献检索核验记录

> 用途：给「AI 日志」提供逐条校验证据，证明 references.bib 无引用造假（0 分红线）。
> 核验日期：2026-09-27。所有作者名单、标题、DOI 均来自以下权威源，未臆造。

## 核验方法与源

| 源 | 说明 |
|---|---|
| arXiv abstract page | 论文作者块（Authors: 行）为权威作者名单，用于补齐 OpenAlex 截断的中间作者 |
| OpenAlex API | `select=authorships` 取标题/DOI/年份/作者 |
| Crossref API | 已发表论文（ACM/Springer/Nature）的权威元数据 |
| DataCite | arXiv 前缀 DOI（10.48550）的唯一权威源 |

## 逐条记录（citation key → 证据）

1. **cobbe2021training** — Training Verifiers to Solve Math Word Problems (GSM8K)
   - arXiv:2110.14168；OpenAlex W3210904070；12 位作者齐全；2021-10-27。
   - 关键数据：8.5K 道小学数学应用题；verifier 在测试时对候选解排序。

2. **deepseek2025r1** — DeepSeek-R1 incentivizes reasoning in LLMs through reinforcement learning
   - Nature，DOI 10.1038/s41586-025-09422-z；2025。集体署名 DeepSeek-AI（arXiv:2501.12948 同源）。
   - 关键数据：纯 RL 推理、显式 CoT；完整 200+ 作者名单存于结果 ref（web_fetch.1c5251de...），用集体署名规避臃肿且不失真。

3. **hendrycks2021measuring** — Measuring Mathematical Problem Solving With the MATH Dataset
   - arXiv:2103.03874；OpenAlex W3134642945；8 位作者齐全；2021-03-05。
   - 关键数据：12,500 道竞赛级难题，每题含完整分步解答。

4. **lewkowycz2022solving** — Solving Quantitative Reasoning Problems with Language Models (Minerva)
   - arXiv:2206.14858；OpenAlex W4283768109；14 位作者齐全；2022。
   - 关键数据：Minerva 约答对 200+ 道本科级量化题的三分之一。

5. **wang2023plan** — Plan-and-Solve Prompting
   - ACL 2023，DOI 10.18653/v1/2023.acl-long.147；arXiv:2305.04091（本页补齐 Hu/Lan/Lee 全名）。
   - 7 位作者：Lei Wang, Wanyu Xu, Yihuai Lan, Zhiqiang Hu, Yunshi Lan, Roy Ka-Wei Lee, Ee-Peng Lim。

6. **wang2022selfconsistency** — Self-Consistency Improves Chain of Thought Reasoning
   - arXiv:2203.11171；OpenAlex W4221161695；8 位作者齐全；2022。
   - 关键数据：GSM8K +17.9%，SVAMP +11.0%，AQuA +12.2%，StrategyQA +6.4%，ARC-challenge +3.9%。

7. **wei2022chain** — Chain-of-Thought Prompting Elicits Reasoning
   - arXiv:2201.11903；DOI 10.48550/arXiv.2201.11903（DataCite）；9 位作者齐全；2022-01-28。
   - 注意：OpenAlex W4221143046 记录损坏（标题/摘要错误），故改用 DataCite 元数据。

8. **azerbayev2023proofnet** — ProofNet
   - arXiv:2302.12433；OpenAlex W4322616316；6 位作者齐全；2023-02-24。
   - 关键数据：371 个例子，Lean 3，本科级；方法 = prompt retrieval + distilled backtranslation。

9. **fulton2015keymaera** — KeYmaera X
   - CADE-25，DOI 10.1007/978-3-319-21401-6_36；OpenAlex W1590463358；5 位作者齐全；2015。
   - 作者：Nathan Fulton, Stefan Mitsch, Jan-David Quesel, Marcus Völp, André Platzer。

10. **wang2023legoprover** — LEGO-Prover
    - arXiv:2310.00656；OpenAlex W4387323780；14 位作者齐全；2023。
    - 关键数据：miniF2F-valid 48.0%→57.0%，test 45.5%→47.1%；生成 20,000+ 个 skills；消融 47.1%→50.4%。

11. **yang2023leandojo** — LeanDojo
    - arXiv:2306.15626；OpenAlex W4382498654；9 位作者齐全；2023；NeurIPS 2023 Datasets & Benchmarks Track（oral）。
    - 关键数据：ReProver；MIT 许可；基准 98,734 条定理；单 GPU 一周训练。

12. **schirmer2006verification** — Verification of Sequential Imperative Programs in Isabelle/HOL
    - OpenAlex W14193191；单人作者 Norbert Schirmer；2006；无 DOI。

13. **sozeau2019coqcoqcorrect** — Coq Coq correct!
    - Crossref DOI 10.1145/3371076；PACMPL 4(POPL):1–28；5 位作者齐全；2019-12-20。
    - 作者：Matthieu Sozeau, Simon Boulier, Yannick Forster, Nicolas Tabareau, Théo Winterhalter。

14. **wu2022autoformalization** — Autoformalization with Large Language Models
    - arXiv:2205.12615；OpenAlex W4282045675；7 位作者齐全；2022-05-25。
